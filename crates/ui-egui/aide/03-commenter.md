# Commenter et annoter

Ouvrez l'outil **Ajouter des commentaires** (dans **Tous les outils**). Une barre d'outils s'affiche au-dessus du document.

## Les annotations

- **Note** : cliquez dans la page, puis écrivez votre commentaire.
- **Surligner le texte**, souligner, barrer : sélectionnez le texte voulu avec l'outil choisi.
- **Ajouter du texte** : écrivez directement sur la page.
- **Dessiner** : traits à main levée, flèches, rectangles, ellipses.
- **Ajouter un tampon** (outil à part dans **Tous les outils**) : posez un tampon de la palette, ou un tampon créé à partir de votre propre image.

La couleur, l'épaisseur et l'opacité se règlent dans la barre de l'outil. Un clic droit sur une annotation ouvre ses propriétés.

## Discuter d'un document

Le **Panneau des commentaires** (**Ctrl+M**) liste toutes les annotations. Vous pouvez y **Répondre**, marquer un commentaire comme traité, filtrer par auteur ou par type, et sauter d'un commentaire à l'autre.

Le nom affiché comme auteur se règle dans les Préférences.

## Le correcteur d'orthographe

Dans les commentaires, les réponses et le texte ajouté, les mots inconnus sont soulignés d'une vague rouge.

- **Clic droit** sur le mot : choisissez une correction.
- **Tout ignorer** : le mot n'est plus signalé jusqu'à la fermeture de Lusk PDF.
- **Ajouter au dictionnaire** : le mot est ajouté à votre dictionnaire personnel, gardé sur votre ordinateur.

La langue du correcteur (français, breton, anglais) ou son arrêt se choisit dans **Préférences › Orthographe**.
