# Organiser, modifier et protéger

## Organiser les pages

L'outil **Organiser les pages** affiche toutes les pages en grille :

- faites glisser une page pour la déplacer ;
- faites pivoter, supprimez, dupliquez ou extrayez les pages sélectionnées ;
- insérez une page blanche ou les pages d'un autre fichier ;
- **Fractionner le document…** le découpe en plusieurs fichiers.

**Combiner des fichiers** réunit plusieurs PDF (et des images) en un seul document, dans l'ordre de votre choix.

## Modifier le contenu

L'outil **Modifier un PDF** retouche le texte et les images existants : cliquez dans un paragraphe pour le corriger, déplacez ou remplacez une image. Il ajoute aussi en-têtes et pieds de page (avec la numérotation des pages), filigranes et arrière-plans.

## Biffer des informations

**Biffer un PDF** efface définitivement du texte ou des zones (adresse, numéro…) : contrairement à un rectangle noir posé dessus, l'information disparaît vraiment du fichier. Lusk PDF enregistre le résultat dans un nouveau fichier, pour garder l'original.

## Protéger

**Protéger un PDF** demande un mot de passe pour ouvrir le document, ou limite l'impression, la copie et les modifications. Gardez le mot de passe en lieu sûr : sans lui, le document ne peut plus être ouvert.

## Alléger un fichier

**Compresser un PDF** réduit le poids d'un document (images, polices, données inutiles), par exemple pour l'envoyer par e-mail.
