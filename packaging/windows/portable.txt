Lusk PDF, version portable

Tant que ce fichier est à côté de pdfcraft.exe, Lusk PDF garde ses réglages, ses journaux, ses
copies de récupération et les nouvelles identités numériques dans le dossier PdfCraftData, à côté
de lui, et n'écrit rien dans %APPDATA% ni dans %LOCALAPPDATA%. Copiez tout le dossier pour emporter
Lusk PDF avec ses réglages.

Supprimez ce fichier pour utiliser les dossiers habituels de votre compte (%APPDATA%\PdfCraft et
%LOCALAPPDATA%\PdfCraft). Si PdfCraftData ne peut pas être écrit (par exemple sur un support en
lecture seule), Lusk PDF le signale et utilise les dossiers de votre compte.

Ouvrir les fichiers PDF avec cette copie

La version portable ne s'inscrit pas auprès de Windows : la choisir dans « Ouvrir avec » peut ne pas
être retenu. Pour la proposer dans Paramètres > Applications > Applications par défaut, ouvrez
PowerShell dans ce dossier et lancez :

  $exe = (Resolve-Path .\pdfcraft.exe).Path
  $c = "HKCU:\Software\Classes"
  $cap = "HKCU:\Software\LuskPdf.Portable\Capabilities"
  foreach ($k in "$c\LuskPdf.Portable\shell\open\command", "$c\.pdf\OpenWithProgids",
                 "$cap\FileAssociations", "HKCU:\Software\RegisteredApplications") {
    if (!(Test-Path $k)) { New-Item -Path $k -Force | Out-Null }
  }
  Set-Item -Path "$c\LuskPdf.Portable" -Value "Document PDF"
  Set-Item -Path "$c\LuskPdf.Portable\shell\open\command" -Value "`"$exe`" `"%1`""
  New-ItemProperty -Path "$c\.pdf\OpenWithProgids" -Name LuskPdf.Portable -Value "" -PropertyType String -Force | Out-Null
  New-ItemProperty -Path $cap -Name ApplicationName -Value "Lusk PDF (portable)" -PropertyType String -Force | Out-Null
  New-ItemProperty -Path $cap -Name ApplicationDescription -Value "Lecteur et editeur de PDF libre" -PropertyType String -Force | Out-Null
  New-ItemProperty -Path "$cap\FileAssociations" -Name .pdf -Value LuskPdf.Portable -PropertyType String -Force | Out-Null
  New-ItemProperty -Path "HKCU:\Software\RegisteredApplications" -Name "Lusk PDF (portable)" -Value "Software\LuskPdf.Portable\Capabilities" -PropertyType String -Force | Out-Null

Ouvrez ensuite Paramètres > Applications > Applications par défaut, cherchez .pdf (ou Lusk PDF) et
choisissez-le. Cela ne change que les réglages de votre compte (HKEY_CURRENT_USER), et ne change
pas à lui seul l'application par défaut. Si vous déplacez ou renommez ce dossier, relancez ces
lignes depuis le nouvel emplacement.

Pour revenir en arrière, choisissez d'abord une autre application pour .pdf dans Paramètres >
Applications > Applications par défaut (sinon Windows continue d'envoyer les PDF vers l'entrée
supprimée), puis lancez :

  Remove-Item -Path "HKCU:\Software\Classes\LuskPdf.Portable", "HKCU:\Software\LuskPdf.Portable" -Recurse -ErrorAction SilentlyContinue
  Remove-ItemProperty -Path "HKCU:\Software\Classes\.pdf\OpenWithProgids" -Name LuskPdf.Portable -ErrorAction SilentlyContinue
  Remove-ItemProperty -Path "HKCU:\Software\RegisteredApplications" -Name "Lusk PDF (portable)" -ErrorAction SilentlyContinue
  foreach ($k in "HKCU:\Software\Classes\.pdf\OpenWithProgids", "HKCU:\Software\Classes\.pdf") {
    $i = Get-Item -Path $k -ErrorAction SilentlyContinue
    if ($i -and $i.ValueCount -eq 0 -and $i.SubKeyCount -eq 0) { Remove-Item -Path $k }
  }

Les dernières lignes ne suppriment les clés .pdf que lorsqu'elles sont vides : l'entrée d'une autre
application y reste.
